# Hospital Workflow Guide

## 🏥 How Hospitals Use OrgFlow

This guide explains how hospital staff can use OrgFlow for daily organ donation operations.

---

## 🎯 Daily Hospital Workflow

### **Step 1: Morning Check-In**
1. **Login to OrgFlow:**
   - Visit the live application
   - Enter hospital credentials
   - Access dashboard overview

2. **Review Available Organs:**
   - Check "Live Registry" tab
   - See organs available across all hospitals
   - Note any matches for your patients

### **Step 2: Organ Registration** (When Organs Become Available)

#### **📝 Register a New Organ:**

```bash
# Navigate to Live Registry → "Register New Organ"
```

**Required Information:**
- **Organ Type:** Heart, Kidney, Liver, Lung, Pancreas, Cornea
- **Blood Type:** A+, A-, B+, B-, AB+, AB-, O+, O-
- **Donor Information:** Age, medical history, contraindications
- **Hospital Location:** Your hospital's name
- **Urgency Level:** High, Medium, Low

**What Happens Next:**
- ✅ Organ gets minted as NFT on Hedera blockchain
- ✅ Real-time notification sent to all hospitals
- ✅ Organ appears in network-wide registry
- ✅ Audit trail created for compliance

### **Step 3: Receiving Organ Requests**

#### **🔔 When Another Hospital Requests Your Organ:**

1. **Notification Appears:**
   - Bell icon in navigation shows pending requests
   - Request details: requesting hospital, reason, patient info

2. **Evaluate Request:**
   - Check medical compatibility
   - Verify requesting hospital credentials
   - Confirm transportation logistics

3. **Accept or Reject:**
   - **Accept:** Organ status changes to "In Transit"
   - **Reject:** Organ remains available for others

### **Step 4: Organ Transfer Process**

#### **📦 Transferring an Organ:**

```bash
# Registry → Select organ → Click "Transfer"
```

**Transfer Workflow:**
1. **Select Recipient Hospital**
2. **Enter Transport Details:**
   - Method: Ground ambulance, air ambulance, helicopter
   - Estimated arrival time
   - Driver/coordinator contact info
   - Chain of custody requirements

3. **Monitor Progress:**
   - Real-time GPS tracking (future feature)
   - Temperature monitoring alerts
   - Automatic status updates

#### **📥 Receiving an Organ:**

1. **Arrival Notification:**
   - OrgFlow alerts your team when organ is 30 minutes away
   - fisiPrepare surgical team and OR

2. **Confirm Receipt:**
   - Hospital staff clicks "Mark as Arrived"
   - Organ status updates to "Available"
   - Quality assurance checklist completes
   - Surgeon notified of readiness

### **Step 5: Transplant Completion**

#### **🏥 During Surgery:**
- Surgical team accesses patient records
- Organ specifics reviewed (NFT metadata)
- Complete medical history available

#### **✅ Post-Transplant Recording:**
```bash
# Select organ → Click "Transplant" button
```

**Required Transplant Data:**
- **Patient Information:** Name, age, medical ID
- **Surgical Team:** Lead surgeon, assisting physicians
- **Procedure Details:**
  - Surgery start/end times
  - Complications encountered
  - Organ quality assessment
  - Outcome status

**Automatic Actions:**
- 📋 NFT "burned" on Hedera (organ no longer available)
- 📊 Transplant statistics updated
- 🏥 Hospital performance metrics recorded
- 📈 Anonymous outcome data for research

## ❓ Troubleshooting

### **Common Issues:**

**❌ Can't Register Organ:**
- Check all required fields completed
- Verify Hedera network connectivity
- Contact tech support if blockchain issues

**❌ Request Not Received:**
- Other hospital may be offline
- Check network notifications
- Manual phone follow-up for critical cases

**❌ Transfer Status Not Updating:**
- Confirm transportation team has OrgFlow app
- Check GPS signal if applicable
- Manual status updates available
