## 🎯 What is OrgFlow?

OrgFlow revolutionizes organ donation by providing:

- **🔒 Immutable Blockchain Records** - Every organ transaction is cryptographically secured
- **📊 Real-Time Hospital Coordination** - Instant organ availability across hospital networks
- **⚡ Life-Saving Speed** - Automated matching and fraud prevention
- **🌐 Global Accessibility** - Works with existing hospital workflows

Instead of phone calls and paperwork, hospitals get instant, verifiable organ tracking through blockchain technology.

## 🚀 Getting Started

### **5-Minute Quick Start**
1. **Clone Repository:**
   ```bash
   git clone https://github.com/WilsonNdiko/OrganTrack-Organ-Donation-tracking-System.git
   cd organflow-hash-care-main
   ```

2. **Install & Run:**
   ```bash
   # Install dependencies
   npm install

   # Start development server
   npm run dev

   # In new terminal, start backend
   cd ../backend
   npm install
   npm start
   ```

3. **Access OrgFlow:**
   - **Frontend:** http://localhost:8081
   - **Backend API:** http://localhost:3002

4. **Test the System:**
   - Register organs using the live registry
   - Create hospital transfer requests
   - View real-time analytics

### **Live Demo**
🌐 **Try OrgFlow Now:** [https://organ-track-organ-donation-tracking.vercel.app/](https://organ-track-organ-donation-tracking.vercel.app/)

## 🎯 Core Features

### 🏥 **Hospital Operations**
- **Real-time Organ Registration:** Secure NFT creation for each organ
- **Smart Matching:** Compatible blood types and medical compatibility
- **Hospital Transfers:** Seamless coordination between institutions
- **Audit Trail:** Complete blockchain-verified history

### 🔄 **System Architecture**
```
🌐 Frontend (React)     🖧 Backend (Node.js)     🏗️ Blockchain (Hedera)
       ↓                        ↓                        ↓
   User Interface    ←→   API Endpoints      ←→    NFT Registry
       ↓                        ↓                        ↓
 Real-Time Updates   ←→   WebSocket Server   ←→  Smart Contracts
```

### 🔐 **Security & Compliance**
- **HIPAA Compliant** healthcare data handling
- **Fraud Prevention** through immutable blockchain records
- **Access Control** with hospital-based authentication
- **Real-time Monitoring** of all critical operations
